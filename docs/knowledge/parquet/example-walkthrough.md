# `tmp/example.parquet` 拆解

先读完 [what-is-parquet.md](what-is-parquet.md)。本文是对照用的，不是入门。

文件 594 字节，DuckDB 1.5.5 写出。3 行：`(1, Alice, 25, Beijing)` …

磁盘上按列排：`1,2,3` 一坨，`Alice,Bob,Charlie` 一坨。hex 里看到名字挤在一起，是列存，不是行存坏了。

Thrift 字节规则：[what-is-thrift.md](../Thrift/what-is-thrift.md)。

## 地图

```
0x0000  PAR1
0x0004  id    从 4 起，37 字节
0x0029  name  从 41 起，52 字节
0x005d  age   从 93 起
0x0082  city  从 130 起
0x00be  FileMetaData          396 字节
0x024a  长度 396（8c 01 00 00）
0x024e  PAR1
```

`594 - 8 - 396 = 190` → 目录从 `0xbe` 开始。定位页用 `data_page_offset`，这份文件里 `file_offset` 是 0。

列是 OPTIONAL：就算没有 null，页里仍有 definition level（0=空，1=有值）。

| 列 | offset | 压缩/未压缩 | codec | min | max |
|----|--------|-------------|-------|-----|-----|
| id | 4 | 37 / 35 | SNAPPY | 1 | 3 |
| name | 41 | 52 / 50 | SNAPPY | Alice | Charlie |
| age | 93 | 37 / 35 | SNAPPY | 25 | 30 |
| city | 130 | 60 / 58 | SNAPPY | Beijing | Shenzhen |

DuckDB 的 `encodings` 列只显示了 PLAIN；页头里 levels 另标了 RLE。

## 两套语法

| 区域 | 什么编码 |
|------|----------|
| 目录 `FileMetaData`、每个 `PageHeader` | Thrift Compact |
| 页里的值、level、Snappy | **不是** Thrift |

## 读 / 写（引擎视角）

读：`pread` 尾 8 字节 → 目录 → 只取需要的列 → PageHeader → 解压 → levels → values → Vector。null 走 validity，不要解成 0。

写：先 `PAR1` 和各列数据（边写边记 offset / min-max），最后再写目录 + 长度 + `PAR1`。目录放尾巴是因为写的时候还不知道这些数。

## 手拆 `id`（阶段 2 才需要）

offset 4 的 PageHeader（17 字节）：DATA_PAGE，未压缩 18，压缩 20，3 个值，PLAIN，levels 用 RLE。

后面 Snappy 几乎没压（文件太小）：`12 44` + 18 字节原文。所以压缩后体积反而略大。

扁平 OPTIONAL → 没有 repetition levels。18 字节 payload：

```
02 00 00 00     def-level 流长度 = 2
06 01           RLE：3 个值都是 1（都有值）
01 00 00 00     1
02 00 00 00     2
03 00 00 00     3
```

`name` 同构，PLAIN BYTE_ARRAY = 4 字节长度 + 内容（`Alice` / `Bob` / `Charlie`）。

目录入口 `0xbe`：`15 02` = version 1；`19 5c` = 5 个 SchemaElement。

## 这份文件有什么 / 先别管

有：footer、一个 row group、每列一页 Data Page v1、OPTIONAL + def level、PLAIN INT32/BYTE_ARRAY、SNAPPY（literal）、min/max。

先别管：字典、Page v2、DELTA、ZSTD、LIST/MAP、多 row group、bloom / column index。

窄契约：无压缩或 Snappy、PLAIN、扁平 OPTIONAL、INT32/BYTE_ARRAY、每列一页。不支持的 encoding 报错，不要静默变 null。

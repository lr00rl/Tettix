主名用 **Tettix**。中文叫 **知了**。作者栏写 **cdcd / Christopher Dylan**。

---

**Tettix** 是希腊语的蝉（τέττιξ）。短、能注册、读起来像 Velox / Umbra 这类引擎，又和你的艺名 **cicada** 是翻译关系，不是撞车。命令行就用 `tettix`。

中文 **知了** 有两层：蝉，以及「已经知道」——统计裁剪、谓词下推，正好是这种引擎靠吃饭的东西。

署名分层，别把所有马甲都塞进产品名：

| 位置 | 用什么 |
|---|---|
| 引擎 | Tettix |
| 中文 | 知了 |
| LICENSE / 论文作者 | Christopher Dylan |
| GitHub 用户 | cdcd |
| 仓库 | `tettix` |
| 不想露真名时 | cicada |
| `lr00rl` | 内部彩蛋、构建号、主题色，不要当产品名 |

---

不要用这些当主名：

- **cdcd**：数据圈里 CDC = Change Data Capture，TiCDC 已经占坑，搜都搜不到你。
- **Cicada** 当正式名：CI 产品、安全扫描器、Cicada 3301，重名到无法占领。当艺名署名可以，当引擎名不行。
- **Tymbal**：意象合适（蝉的发声器），但已经被「Cicada + Tymbal」安全工具配对用过，还会被拼成 Timbal。
- **Duck / Ti / House 变体**：一看就像仿写。

---

如果 Tettix 你念着别扭，备选只有一个：**Chirr**（蝉鸣的拟声，CLI 是 `chirr`）。再不行就仓库名 **cicadaql**、产品名仍然对外解释为 cicada 写的引擎——那是把脸贴在产品上的路线，SEO 会很差，个人项目可以接受。

一句话：**引擎 Tettix，中文知了，人是 cdcd。**
